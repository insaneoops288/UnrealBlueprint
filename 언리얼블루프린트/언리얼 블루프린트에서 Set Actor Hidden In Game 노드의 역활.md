# **Set Actor Hidden In Game 노드 상세 가이드**

Set Actor Hidden In Game 노드는 언리얼 엔진에서 액터(Actor)의 가시성(Visibility)을 제어하는 가장 기본적인 노드 중 하나입니다.

## **1\. 주요 역할**

이 노드의 핵심 역할은 "게임 플레이 중에 해당 액터를 렌더링(표시)할 것인가?"를 결정하는 것입니다.

* **True (체크됨):** 액터가 게임 화면에서 사라집니다. (숨김 상태)  
* **False (체크 해제):** 액터가 게임 화면에 다시 나타납니다. (표시 상태)

## **2\. 노드 구성 요소**

* **Target (대상):** 가시성을 변경할 액터입니다. 자기 자신(Self)을 대상으로 하거나, 참조된 다른 액터를 연결할 수 있습니다.  
* **New Hidden (새 숨김 상태):** 부울(Boolean) 값입니다. 숨기려면 이 값을 활성화합니다.

## **3\. 핵심 특징 및 주의사항 (중요)**

### **A. 렌더링 vs 콜리전 (Collision)**

가장 많이 오해하는 부분입니다. Set Actor Hidden In Game은 **렌더링(시각적 요소)만** 제어합니다.

* 액터를 숨겨도 **콜리전(충돌 판정)은 그대로 유지**됩니다.  
* 만약 투명해진 벽을 플레이어가 통과하지 못하게 하려면, 추가적으로 Set Actor Enable Collision 노드를 사용해 충돌을 꺼주어야 합니다.

### **B. 퍼포먼스 (Performance)**

액터가 숨겨지면 그래픽 카드(GPU)는 해당 액터를 그리지 않으므로 드로우 콜(Draw Call)이 줄어들어 성능 최적화에 도움이 됩니다.

### **C. 컴포넌트 단위 제어와의 차이**

* Set Actor Hidden In Game: 액터 전체(포함된 모든 스태틱 메시, 파티클 등)를 한 번에 숨깁니다.  
* Set Visibility (컴포넌트 노드): 액터 내부의 특정 컴포넌트(예: 캐릭터의 모자만)만 숨길 때 사용합니다.

## **4\. 실전 활용 사례**

* **아이템 획득:** 플레이어가 아이템을 먹었을 때, Destroy Actor로 완전히 삭제하기 전 효과를 주기 위해 잠시 숨기는 경우.  
* **플래시라이트/배터리:** 특정 상황에서만 보여야 하는 길이나 힌트 오브젝트 제어.  
* **컷신(연출):** 특정 연출 타이밍에 등장인물을 나타나게 하거나 사라지게 할 때.

## **5\. 블루프린트 구성 예시**

보통 다음과 같은 흐름으로 사용됩니다:

1. **이벤트 발생** (예: OnComponentBeginOverlap)  
2. **조건 확인** (예: Is Player?)  
3. **Set Actor Hidden In Game** (New Hidden \= True)  
4. **Set Actor Enable Collision** (New Collision \= No Collision) \-\> *완전한 제거 효과를 원할 경우*

이 노드는 단순히 "안 보이게 하는 것" 이상의 최적화와 게임 로직 설계에 필수적인 도구입니다. 상황에 따라 콜리전 제어 노드와 함께 사용하는 습관을 들이는 것이 좋습니다.
