# **언리얼 블루프린트: 이벤트 디스패처 바인드 위치 찾는 방법**

이벤트 디스패처는 "누가 이 이벤트를 듣고 있는지(Bind)"를 찾는 것이 디버깅의 핵심입니다. 다음 세 가지 방법을 통해 바인드된 위치를 빠르게 찾을 수 있습니다.

### **1\. '레퍼런스 찾기' (가장 빠른 방법)**

해당 이벤트 디스패처가 정의된 블루프린트 안에서 바로 찾는 방법입니다.

1. **\[내 블루프린트(My Blueprint)\]** 패널에서 해당 이벤트 디스패처 이름을 마우스 오른쪽 버튼으로 클릭합니다.  
2. \[레퍼런스 찾기(Find References)\]를 선택합니다.  
3. 하단에 **\[찾기 결과(Find Results)\]** 창이 뜨며, 해당 디스패처를 사용한 모든 노드가 나열됩니다.  
   * 여기서 "Bind Event to \[디스패처이름\]"이라고 적힌 노드들을 확인하면 됩니다.

### **2\. '전체 블루프린트 검색' (다른 에셋에서 바인드한 경우)**

만약 다른 블루프린트 클래스나 레벨 블루프린트에서 해당 이벤트를 바인드했다면, 전역 검색을 사용해야 합니다.

1. 단축키 Ctrl \+ Shift \+ F를 눌러 **\[전체 블루프린트 찾기\]** 창을 엽니다.  
2. 검색창에 Bind \[이벤트디스패처이름\]을 입력하고 엔터를 누릅니다.  
3. 프로젝트 내의 모든 블루프린트를 스캔하여 해당 디스패처에 이벤트를 바인딩한 노드를 모두 찾아줍니다.

### **3\. '노드에서 직접 찾기'**

이미 블루프린트 그래프에 배치된 디스패처 관련 노드(Call, Bind, Unbind 등)가 있다면:

1. 그래프 상의 노드를 마우스 오른쪽 버튼으로 클릭합니다.  
2. \[레퍼런스 찾기(Find References)\]를 클릭합니다.  
3. 현재 블루프린트 내에서 해당 디스패처와 관련된 모든 연결 상태를 보여줍니다.

### **💡 팁: 검색 결과 필터링**

검색 결과가 너무 많을 때는 다음 키워드를 함께 확인하세요.

* **Bind Event to...**: 이 이벤트를 수신하기 위해 연결된 곳입니다.  
* **Call...**: 이 이벤트를 발생(발행)시키는 곳입니다.  
* **Unbind...**: 더 이상 이벤트를 듣지 않도록 연결을 해제하는 곳입니다.

만약 C++에서 정의된 디스패처라면, IDE(Visual Studio 등)에서 해당 변수명을 전체 검색(Ctrl \+ Shift \+ F)하여 .AddDynamic 또는 .BindUFunction이 사용된 위치를 찾으면 됩니다.
